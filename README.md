# פרויקט גמר · ForSight Robotics

יישום כלים מתקדמים בניהול מלאי בהתאם לעקרונות Lean · נועם ועמרי · המרכז האקדמי רופין, ייצור ושירות בסביבה דיגיטלית, תשפ״ז

**האתר:** https://noamleadbound.github.io/forsight-final-project/

## מה יש כאן
| עמוד | קובץ |
|---|---|
| טיימליין (דף הבית), עם סימון "קרה" לכל אבן דרך | `index.html` |
| משימות: לוח לעשות / בעבודה / הושלם | `tasks.html` |
| סיכומי פגישות | `meetings.html` |
| כתיבה והערות: טיוטות לפרקי הדוחות, הערות מנחה, החלטות | `notes.html` |
| מחקר על החברה | `company.html` |
| יום האפיון | `workpack.html` |
| מצגות (ובתוכן מצגת הפתיחה, `deck-opening.html`) | `presentations.html` |
| קורס הכנה | `course.html` |
| מושגים | `glossary.html` |

## זיכרון משותף
כל מה שמסמנים או כותבים באתר (צ׳קבוקסים, שדות, טבלת ממצאים, משימות, פגישות, מסמכים) נשמר ב-Supabase, וגלוי רק למיילים שברשימת הצוות (`supabase/schema.sql`). הדפים עצמם פתוחים למי שיש לו את הקישור, ולכן אין בהם פרטי קשר.

## עדכון התוכן
עורכים את `src/`, מריצים `python3 build.py`, ודוחפים (`git push`). הסקריפט בונה גם עותק מקומי עם פרטי הקשר (מתוך `private.json`, שלא נכנס ל-git), ועוצר אם טלפון או מייל עומדים להתפרסם.
