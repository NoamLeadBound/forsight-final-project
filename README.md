# פרויקט גמר · ForSight Robotics

יישום כלים מתקדמים בניהול מלאי בהתאם לעקרונות Lean · נועם ועמרי · המרכז האקדמי רופין, ייצור ושירות בסביבה דיגיטלית, תשפ״ז

**האתר:** https://noamleadbound.github.io/forsight-final-project/

## מה יש כאן
| קובץ באתר | מה זה |
|---|---|
| `index.html` | ניהול הפרויקט: משימות, אבני דרך, פגישות, החלטות, הערות מנחה |
| `timeline.html` | אבני הדרך, הקריטריונים והמשקלות |
| `company.html` | הכרת החברה |
| `workpack.html` | תיק עבודה ליום האפיון |
| `deck.html` | מצגת פתיחה לפגישת האפיון |
| `course.html` | קורס הכנה: ניהול מלאי ו-Lean |

## זיכרון משותף
כל מה שמסמנים או כותבים באתר (צ׳קבוקסים, שדות, טבלת ממצאים, משימות, פגישות) נשמר ב-Supabase, וגלוי רק למיילים שברשימת הצוות (`supabase/schema.sql`). הדפים עצמם פתוחים למי שיש לו את הקישור, ולכן אין בהם פרטי קשר.

## עדכון התוכן
עורכים את `src/`, מריצים `python3 build.py`, ודוחפים (`git push`). הסקריפט בונה גם עותק מקומי עם פרטי הקשר (מתוך `private.json`, שלא נכנס ל-git), ועוצר אם טלפון או מייל עומדים להתפרסם.
